# CodeAlpha Task 2 – Exploratory Data Analysis

## Project Overview
This project is completed as part of the CodeAlpha Data Science Internship.

The project focuses on Exploratory Data Analysis (EDA) of a Customer Churn dataset to understand the data, identify patterns, and gain useful insights through analysis and visualization.

## Dataset
The dataset used in this project is `Customer Churn.csv`.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Project File
- `CodeAlpha_Task2_EDA.ipynb` – Complete EDA notebook
- `Customer Churn.csv` – Dataset used for analysis

## Key Analysis
- Data loading and inspection
- Data cleaning
- Handling missing values
- Exploratory data analysis
- Data visualization
- Identifying patterns and relationships
- Customer churn analysis

## Conclusion
The analysis provides useful insights into customer churn patterns and demonstrates the use of Python-based Exploratory Data Analysis techniques.
